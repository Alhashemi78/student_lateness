# مرجع مشروع الفعاليات المدرسية
آخر تحديث: 13 أكتوبر 2026، بتوقيت البحرين.

## الهوية والربط
- المالك: زياد محمد الهاشمي، المدير المساعد.
- المدرسة: مدرسة النعيم الثانوية للبنين.
- العام: 2026-2027م. المشروع تجريبي؛ مراجعة الأمان والاختبارات قبل نشره للموظفين.
- المستودع: Alhashemi78/student_lateness، الفرع main.
- الواجهة: school-events/index.html؛ HTML/CSS/JavaScript عربية RTL ومتجاوبة.
- Supabase: Recording the delay، المعرّف chkczeusxnifayswhvqo.
- قاعدة مشتركة مع تطبيق التأخير السابق؛ لا تعدّل جداول التأخير أثناء العمل على الفعاليات.
- الجداول: school_events، school_event_access، school_event_documentation، school_event_photos.
- المصادقة: Supabase Auth؛ الوصول لقائمة الموظفين المعتمدة، وصلاحيات منفصلة للإدارة.

## الصور: ما تم فعليًا
- Cloudinary cloud name: uot1nayb.
- المجلد: الفعاليات المدرسية 2026-2027.
- نُقلت 8 صور من Supabase إلى Cloudinary، وفُحص تنزيل كل صورة موقعة.
- نوع الصور authenticated؛ لا تُستخدم صور عامة تلقائيًا.
- بقيت الملفات الأصلية في bucket خاص school-event-private مؤقتًا حتى اختبار الواجهة بالحساب الفعلي؛ المساحة الأصلية لم تتحرر.
- school_event_photos يحتفظ بـ storage_path كمعرّف توافق، وأضيفت cloudinary_public_id وcloudinary_version وcloudinary_format. storage_path للصور الجديدة ليس ملفًا فعليًا في Supabase.
- خدمة school-events-images في Supabase Edge Functions ترفع الصور وتقرأها بصلاحيات المستخدم.
- مصدر الخدمة: supabase/functions/school-events-images/index.ts.
- مفتاح CLOUDINARY_API_SECRET محفوظ في أسرار Supabase فقط. رُفض المفتاح السابق؛ حدّثه المستخدم ونجح النقل. لا تُنسخ قيم الأسرار إلى أي وثيقة أو مستودع.
- صور الهاتف حتى 25MB تُجهّز قبل الرفع: JPEG وأبعاد لا تتجاوز 1024px مع محاولة خفض الحجم إلى 500KB؛ حد الخادم 2MB.
- الرفع لموظف مصرح صاحب فعالية معتمدة بدأت بالفعل، أو إداري مصرح.
- الخادم يتحقق من هوية المستخدم وقائمة السماح وملكية الفعالية وحالتها ووجود التوثيق.
- قراءة الصورة تمر عبر RLS؛ الخادم يجلب Cloudinary ويعيد bytes دون كشف الروابط الموقعة للواجهة.
- استجابة الصورة application/octet-stream حتى ترجع Supabase Functions Blob؛ الواجهة تتحقق من ترويسة الصورة وتحدد MIME.
- العرض وPDF في school-events/documentation.js؛ تنزيل ZIP في school-events/photo-export.js.
- ضُبط asset_folder في معلمات الرفع الموقّعة، ونُقلت الصور الثماني إلى المجلد دون تغيير public_id أو كسر المراجع.
- أُزيل مسار النقل المؤقت ورمزه بعد التنفيذ.
- اختبار الوصول دون مصادقة أعاد 401. فحص JavaScript syntax نجح.
- لم يُجر اختبار رفع/عرض/PDF/ZIP كامل بحساب مستخدم فعلي بعد التعديل؛ لا تدّع اكتماله.

## الإجراءات عند العودة
1. اقرأ الملفات الحالية من main ولا تعتمد على نسخ قديمة.
2. اختبر الرفع والعرض وتصدير PDF وZIP بحساب مصرح.
3. تحقق من أن المعلم لا يستطيع رفع أو قراءة صور غير مصرح بها، وأن الإداري يعمل وفق صلاحياته.
4. بعد التحقق من الواجهة ومن سلامة النسخ المنقولة، أزل الملفات الأصلية المنقولة فقط عبر Storage API لتوفير المساحة؛ لا تحذف سجلات الصور.
5. راجع أمان المشروع قبل نشره؛ لا تعتبر نجاح SELECT 1 اختبارًا للتطبيق.

## قواعد لجميع المشاريع القادمة
- الأمان وحماية البيانات أولًا. كود الواجهة مرئي عبر F12؛ لا أسرار فيه.
- GitHub للكود، Supabase للبيانات والمصادقة والصلاحيات، Cloudinary للصور مع حماية الوصول المناسبة.
- مجلد Cloudinary مستقل لكل مشروع، ومعرّفات صور معزولة؛ يجب تأكيد مجلد المشروع وإعداد رفعه والتحقق منه.
- مفاتيح سرية في الخادم فقط، والواجهة تستخدم المفتاح العام.
- RLS وسياسات أقل صلاحية؛ لا تعتمد على إخفاء الأزرار. لا تمنح عامة القراءة أو التعديل افتراضيًا.
- تحقّق من الأمان قبل نشر الروابط؛ المستودع كان public عند الفحص ويحتاج خطة استضافة مناسبة إذا جُعل private. خصوصية المستودع لا تخفي كود المتصفح.
- عرض التاريخ والوقت معًا بتوقيت Asia/Bahrain.
- واجهة عربية واضحة للهاتف والكمبيوتر.
- التصدير العربي Excel/PDF مع عنوان كبير وألوان وحدود وشعار عند توفره؛ عنوان الفعاليات: الفعاليات المدرسية العام الدراسي 2026-2027م؛ التذييل يمينًا: إعداد المدير المساعد: زياد الهاشمي.
- التحليلات في صفحة/ورقة مستقلة؛ ناقش الحاجة إليها.
- PWA والتسجيل المؤقت والمزامنة مع منع التكرار متطلبات عامة تحتاج التحقق أو التنفيذ في كل مشروع؛ لا تعتبرها مكتملة تلقائيًا.
- أثناء النقل: احفظ المصدر حتى تتأكد من النسخة المنقولة وروابط العرض والتصدير؛ لا تحذف قبل تحقق كافٍ.
- متابعة اتصال Supabase مرة يوميًا وفق الإعدادات المعتمدة؛ لا تنشئ مهام مكررة أو نسخًا احتياطية دورية دون طلب.
