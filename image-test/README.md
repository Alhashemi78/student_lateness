# تجربة الاسم والصورة

واجهة HTML عربية ضمن `image-test/` في مستودع المدرسة، وجدول مستقل `school_image_records` في مشروع Supabase الحالي. الصور العامة في Cloudinary؛ كتابة السجلات والرفع محميان عبر Edge Function وحساب مصرح له في `school_image_access`.

## تفعيل Cloudinary

في Supabase > Edge Functions > Secrets أضف `CLOUDINARY_API_SECRET` بقيمة API Secret من حساب Cloudinary ذي cloud name `uot1nayb`. لا تضع القيمة في GitHub أو HTML. الـ preset هو `school_images_test` بوضع Signed. باقي إعدادات الربط مضمّنة في وظيفة الخادم.

رابط إعداد الأسرار: https://supabase.com/dashboard/project/chkczeusxnifayswhvqo/functions/secrets

الدخول بالبريد وكلمة المرور الحاليين لتطبيق الفعاليات. الوصول مخصص للحساب المصرح به حاليًا. لا توجد كتابة أو قراءة مجهولة لجدول الصور. Excel يحتوي روابط عامة كما طلب المستخدم. PDF يحتوي الصورة نفسها.

تُحول الصور إلى JPEG أبيض الخلفية بعرض/ارتفاع أقصى 1600px وجودة 85%، مع حد 2MB بعد التحويل و20MB للصورة الأصلية. يرفض الخادم الملفات غير JPEG أو غير الصالحة والحسابات غير المصرح لها.

يُحفظ الطلب المنتظر في IndexedDB بحسب حساب المستخدم ولا يحذف إلا بعد تأكيد الخادم. المعرف الثابت يمنع تكرار التسجيل عند إعادة المحاولة. إعادة الإرسال عند اتصال الجهاز تتطلب أن تكون الصفحة مفتوحة والحساب نفسه مسجلًا. مسح بيانات المتصفح قد يفقد الطلب المنتظر. الصور المحلية المنتظرة لا تُشفّر بشكل مستقل عن حماية جهاز المستخدم.

القائمة الجامعة للمشاريع في `projects/`. الملفات السابقة لم تتغير. مستودع المدرسة الحالي عام في مرحلة التجربة؛ لا يحتوي هذا التطبيق أسرارًا. نقل المستودع إلى خاص لاحقًا يحتاج خطة استضافة مناسبة كما في مرجع المشاريع.
