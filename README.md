# مدرستي الرقمية

بوابة مشاريع مدرسة النعيم الثانوية للبنين. المشروع الحالي: **الفعاليات المدرسية** داخل `school-events/`.

## التشغيل

لا توجد خطوة تثبيت حزم أو بناء. من جذر المستودع:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

الصفحة الرئيسية تعرض البوابة، و`school-events/` يفتح الفعاليات. مسار `projects/` يحوّل إلى البوابة.

الفعاليات تعتمد على Supabase للمصادقة والبيانات والتوثيق، وعلى مكتبات المتصفح من CDN. لم تتغير إعدادات الاتصال أو حسابات المستخدمين عند تحويل الصفحة الرئيسية إلى البوابة. اسم مستودع GitHub ومساره ما زالا `student_lateness` للحفاظ على الروابط الحالية.

أزيلت واجهة التأخير وتجربة الاسم والصورة وكود خدمة رفعها من النسخة الحالية. حذف ملفات المشروع لا يحذف البيانات أو الخدمات المنشورة في Supabase أو Cloudinary، ولا يمسح سجل Git السابق. لا يوجد مشروع باك أب ضمن هذه البوابة.

راجع `school-events/README.md` لتفاصيل الفعاليات وسياسات قاعدة البيانات.

## التثبيت على الهاتف

اضغط «تثبيت التطبيق على الهاتف» من البوابة أو صفحة الفعاليات. يدعم Chrome على Android طلب التثبيت عندما تتوافر شروط المتصفح. في Safari على iPhone استخدم مشاركة ← إضافة إلى الشاشة الرئيسية. يبدأ التطبيق المثبت من بوابة «مدرستي الرقمية» ويضم الفعاليات.

ملف `manifest.webmanifest` و`pwa.js` مشتركان بين الصفحتين. يخزن `sw.js` صفحة عامة لانقطاع الاتصال فقط؛ لا يخزن سجلات أو صورًا أو استجابات مصادقة. تسجيل الدخول وجلب البيانات والحفظ تحتاج اتصالًا بالإنترنت.
