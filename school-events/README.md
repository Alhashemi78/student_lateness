# الفعاليات المدرسية 2026-2027م

تطبيق عربي باتجاه RTL على GitHub Pages مع Supabase Database وAuth. مستقل عن تطبيق التأخير الموجود في جذر المستودع.

## التشغيل

الرابط: https://alhashemi78.github.io/student_lateness/school-events/

1. يمكن تجربة الواجهة والتقارير من زر «جرّب الواجهة والتقارير» دون حفظ أي بيانات تجريبية.
2. حساب الإدارة المصرح له: البريد المرتبط بحساب GitHub للمالك. يُنشأ من واجهة التطبيق لأول مرة بكلمة مرور يختارها المالك، ثم يُؤكَّد البريد.
3. تضيف الإدارة بريد الموظف من صفحة «المراجعة والصلاحيات»، ثم ينشئ الموظف حسابه ويؤكد بريده.
4. إذا لم يعمل تحويل صفحة التأكيد، يمكن نسخ رابط التأكيد من البريد ولصقه في نافذة الدخول لتأكيد الحساب مباشرة. يمكن ضبط رابط التطبيق في Supabase Auth > URL Configuration لتحسين العودة التلقائية.

## الوظائف

- تسجيل فعاليات متعددة الأيام والفترات، مع قسم يدوي عند اختيار «أخرى».
- اقتراح الموظفين من السجلات السابقة حسب القسم، واقتراح الأماكن.
- منع التضارب في المكان والتاريخ والفترة في الواجهة وقاعدة البيانات، مع قفل للكتابات المتزامنة.
- الطلب الجديد قيد المراجعة؛ الإدارة تعتمد أو ترفض، والموظف يعدل طلبه المعلق فقط.
- يحتفظ النظام بالطلبات المرفوضة لأغراض التوثيق، ولا تحجز المكان.
- جدول أسبوعي الأحد–الخميس، وفلاتر تشمل تقاطع الفعاليات متعددة الأيام مع المدة.
- إحصاءات وتحليل حسب القسم والحالة والشهر.
- Excel بصيغة XLSX حقيقية مع خلايا قابلة للتعديل، ألوان وحدود وتجميد العناوين وفلاتر وتحليل ورسوم وصيغ للأيام ونسبة الاعتماد.
- PDF بحجم A4 أفقي، نص عربي مرسوم بدقة لضمان سلامة اتصال الحروف، رؤوس وتوقيع وترقيم متكرر، وتقسيم الصفحات دون قطع الصفوف. النص في PDF مصوّر وليس قابلًا للبحث.
- عنوان التقارير: «الفعاليات المدرسية العام الدراسي 2026-2027م» والتوقيع: «إعداد المدير المساعد:زياد الهاشمي».

## الملفات

`index.html` واجهة التطبيق، `styles.css` التصميم وصفحات PDF، `app.js` الوظائف وSupabase، `exports.js` تنزيل التقارير، `schema.sql` قالب البنية والسياسات؛ يُستبدل فيه البريد النموذجي عند إعداد مشروع آخر.

## الحماية

لا يوجد مفتاح خدمة أو كلمة مرور في الكود. مفتاح Supabase المنشور مخصص للمتصفح؛ الحماية عبر RLS وقائمة بريد مصرح به، ومنع تغيير صاحب السجل ووقت إنشائه. لا وصول لبيانات الفعاليات دون حساب مصرح له. المصادقة تبقى عبر Supabase. يجب استخدام بريد عمل معروف عند إضافة موظف.

## الحدود

لا يتضمن الإصدار إرسال رسائل اعتماد أو رفض تلقائية بالبريد، ولا يستورد قائمة الموظفين من النظام السابق. تؤخذ اقتراحات الموظفين من السجلات الموجودة. يلزم اتصال بالإنترنت للدخول والحفظ وتحميل المكتبات والخطوط. المشاركة تعني مجموع أعداد المشاركين عبر الفعاليات، وليس عدد أشخاص فريدين.
